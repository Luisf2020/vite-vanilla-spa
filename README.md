SPA sin framework con Vite + TypeScript: router por hash y prueba unitaria con Vitest.

> **Transparencia sobre IA:** este proyecto se desarrollo con asistencia de inteligencia artificial (generacion de codigo, revision y documentacion). El codigo fue leido, ejecutado y probado manualmente antes de publicarse. No declara clientes, metricas ni resultados que no puedan verificarse.

## Problema que resuelve

Construir una SPA sin depender de un framework, manteniendo el codigo tipado y probado.

## Solucion implementada

Router por hash en TypeScript con render declarativo por vistas y una prueba unitaria con Vitest sobre el contenedor.

### Funcionalidades principales

- Router por hash propio
- TypeScript estricto
- Prueba unitaria con Vitest
- Build de produccion con Vite

## Stack

- TypeScript
- Vite
- Vitest

## Estructura

```
src/router.ts       # router por hash
src/main.ts         # punto de entrada
src/router.test.ts  # prueba
```

## Puesta en marcha

```bash
npm install
npm run dev
npm test
```
